Keyboard shortcuts let you fly around the app without reaching for the mouse. Press
**⌘ /** anywhere to pop up the full cheatsheet, or open it from the workspace menu →
**Keyboard shortcuts**.

<Callout type="info" title="⌘ on Mac, Ctrl elsewhere">
  Shortcuts are shown for macOS using **⌘**. On Windows and Linux, use **Ctrl** wherever
  you see ⌘ — so **⌘ /** becomes **Ctrl + /**. The cheatsheet detects your system and
  shows the right keys automatically.
</Callout>

## Navigation

Jump straight to a section from anywhere in a workspace:

| Shortcut | Goes to |
| --- | --- |
| **⌘ ⇧ K** | Direct messages |
| **⌘ ⇧ A** | Activity |
| **⌘ ⇧ T** | Threads |
| **⌘ ⇧ S** | Saved items |
| **⌘ ⇧ D** | Drafts |
| **⌘ ⇧ H** | Home |
| **⌘ [** | Go back |
| **⌘ ]** | Go forward |

## General

| Shortcut | What it does |
| --- | --- |
| **⌘ J** | Open the quick switcher — jump to any channel or person by name |
| **⌘ /** | Show (or hide) the keyboard-shortcuts cheatsheet |

## Messaging

While you're writing in the composer:

| Shortcut | What it does |
| --- | --- |
| **Enter** | Send the message |
| **⇧ Enter** | Start a new line without sending |

<Callout title="Shortcuts and your browser">
  A few shortcuts (like **⌘ ⇧ T**) match ones your browser also uses. While the app is
  focused, the app's shortcut wins — so, for example, **⌘ ⇧ T** jumps to Threads rather
  than reopening a closed browser tab.
</Callout>

## On phones

Keyboard shortcuts are meant for a physical keyboard, so the **Keyboard shortcuts** menu
entry is hidden on touch phones. If you pair an external keyboard to a tablet or phone,
the shortcuts still work.
