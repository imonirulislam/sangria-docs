This section is for people **working on** Sangria. It explains how the app is put
together, the shared building blocks you're expected to reuse, and the workflow for
shipping a change safely.

## Stack at a glance

- **Frontend** — Next.js 16 (App Router) + React 19, `jotai` for local state and
  `nuqs` for URL state, Tailwind CSS.
- **Backend** — [Convex](https://convex.dev) (self-hosted locally): schema, queries,
  mutations, actions, HTTP routes, scheduled functions, and components
  (rate-limiter, workpool).
- **Realtime media** — [LiveKit](https://livekit.io) powers huddles.
- **Shells** — Electron (desktop) and Capacitor (iOS/Android), plus a PWA.
- **Package manager** — `bun`.
